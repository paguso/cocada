# cocadoc

Documentation generator for COCADA, written with COCADA.

It reads C headers, pairs each documentation comment with the declaration
that follows it, checks the comments against the COCADA documentation comment
style (`../doc/comment-style.md`), and writes one Markdown page per header.

## Build

```
make build    # build/debug/cocadoc
make test     # build/test/test (unit tests)
```

## Use

Give all the headers at once: references between headers (`#name`, `@see`,
`name.h`) are resolved among the files given.

```
H=$(find ../libcocada*/src -name '*.h' -not -path '*thrdpty*')

# write the documentation pages and an index.md
build/debug/cocadoc -o ../doc/api-md $H

# check the comments against the style rules
build/debug/cocadoc -l $H
```

Options:

| option | does |
|---|---|
| `-o DIR`, `--output DIR` | write Markdown pages (`vec.h` → `DIR/vec.md`) and `DIR/index.md` |
| `-l`, `--lint` | print style warnings as `file:line: warning: [DCn] name: message`, and a count per rule |
| `-s`, `--symbols` | dump the symbol table (debug) |
| `-D`, `--docs` | dump the parsed doc comments (debug) |
| `-d`, `--decls` | dump the declarations (debug) |
| `-t`, `--tokens` | dump the tokens (debug) |

## Pages

Each header gets a page with the module documentation (its file comment),
then sections for types and constants, functions, and macros. Each item has a
`### name` heading, its declaration, and its documentation: brief, details,
parameters (marked **(moved)** for `@param @move`), return value, warnings,
notes, deprecation and see-also. Missing documentation is shown as
*undocumented*.

Links use the heading anchors generated by GitLab and GitHub, e.g.
`vec.md#vec_new`. References to struct fields and enum constants link to their
type.

## Source

| module | does |
|---|---|
| `cdlexer` | splits C source into tokens (doc comments and preprocessor lines are single tokens) |
| `cddecl` | pairs doc comments with declarations, and classifies them |
| `cddoc` | parses a doc comment into fields, and checks the per-comment rules |
| `cdfile` | a loaded header: contents, tokens and declarations |
| `cdsym` | symbol table of all the headers, to resolve references |
| `cdlint` | checks that need the declarations and the symbol table |
| `cdmd` | writes the Markdown pages |
